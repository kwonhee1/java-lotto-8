# java-lotto-precourse

# 기능 
- 로또 결제 금액을 입력 받는다
- 개수 만큼 로또를 발행한다
- 당첨 번호와 보너스 번호를 입력 받는다
- 결과를 출력한다

# 이번 주차 목표
- service 또한 한가지 일만 하게 분리한다 (Service UseCase분리)
- test 코드를 목적을 명확하게 하고 작성한다

# domain 분리
- Lotto
  - 중복되지 않는 6개의 숫자를 가진다
  - 각 숫자의 범위는 1~45이다
- WinningLotto
  - 중복되지 않는 6개의 숫자와 bonus 번호를 가진다
  - 각 숫자의 범위는 1~45이다
  - Lotto와 비교하여 같은 숫자의 개수를 반환한다
- LottoResult
  - 같은 숫자의 개수 만큼 등수를 나눈다
    - 6개 일치 = 1등
    - 5개 일치 + bonus일치 = 2등
    - 5개 일치 = 3등
    - 4개 일치 = 4등
    - 3개 일치 = 5등
  - 등수를 저장한다
  - 총 상금을 계산한다
